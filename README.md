# JavaSwitcher

Fast Java environment switching for Windows. A beautiful CLI tool that lets you quickly switch between different Java installations.

## Features

- **Auto-detection** - Automatically finds all Java installations on your system
- **Fast switching** - Quickly switch JAVA_HOME with arrow keys
- **Beautiful UI** - terminal interface with colors and styling
- **Cross-platform** - Works on Windows, Linux, and macOS
- **Smart sorting** - Current Java version shown first, then sorted by version
- **Multiple Java versions** - Supports Oracle JDK, OpenJDK, Eclipse Adoptium, Amazon Corretto, Zulu, and more
